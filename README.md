# Athenon — athenon.com.br

Site institucional da Athenon. HTML/CSS/JS estáticos, sem build.

## Estrutura
- `index.html` — página única
- `styles.css` — estilos (paleta e tipografia da marca)
- `script.js` — menu mobile, animações de scroll, FAQ, modais dos cases
- `assets/img/` — logo, fotos dos sócios, imagem de compartilhamento
- `assets/favicon/` — ícones do navegador

## Como alterar
Editar o arquivo e dar commit. O Vercel publica sozinho a cada push na branch principal.

Trocar uma foto: substituir o arquivo em `assets/img/` mantendo o mesmo nome.
